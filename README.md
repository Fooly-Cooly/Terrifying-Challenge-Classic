# Terrifying Challenge Classic

> The original Halloween horror movie challenge website.

## Overview

The original first iteration of the **Terrifying Challenge**, an annual October horror movie marathon. Features classic atmospheric rules, category requirements, and curated watchlists designed to test endurance throughout Halloween season.

### Features

- 🎃 **Horror Watchlists:** Categorized by themes, eras, and subgenres.
- 📜 **Challenge Rules:** Official marathon guidelines and scoring criteria.
- 🕹️ **Retro Aesthetic:** Styled with Asciidoctor and retro web typography.
